# 수혈 실험실

ABO식 혈액형의 응집원·응집소를 3D 모형으로 직접 끌어다 맞춰 보며 수혈 관계를 알아보고, 모둠별로 수혈 관계도를 함께 완성하는 수업용 웹앱입니다.

- `index.html` : 학생·교사 화면 (첫 화면, 실험하기, 모둠 관계도, 모둠별 결과, 교사 화면)
- `3d.html` : 3D 실험대 (학생 화면의 '실험하기' 안에 들어가고, 따로 열 수도 있음)
- `apps-script/Code.gs` : 이름·모둠·관계도를 저장하는 구글 앱스크립트 코드
- `img/` : 3D 모형을 렌더링한 이미지, `fonts/` : 제목용 글꼴(Black Han Sans, OFL), `lib/` : Three.js

3D 모형의 크기·모양은 `3d.html`의 "모양 설정"(`SIZE`, `COLOR`)에서 바꿀 수 있습니다.
